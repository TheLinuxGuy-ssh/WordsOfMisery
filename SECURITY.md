# Security Policy

## Supported versions

Words Per Misery is a small static site. Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Use GitHub's private vulnerability reporting feature if it is available for this repository. Otherwise, contact the repository owner through the private contact options on [the maintainer's GitHub profile](https://github.com/TheLinuxGuy-ssh).

Include the affected file, steps to reproduce, impact, and a suggested fix if you have one. Please allow reasonable time for assessment before making the report public.

## Scope

The project does not collect accounts or send typing data to a server. Scores are stored only in the browser's local storage. Reports about unsafe HTML, unexpected data transmission, dependency issues, or GitHub Pages configuration are welcome.
