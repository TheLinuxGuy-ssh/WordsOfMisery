# Contributor Covenant Code of Conduct

## Our pledge

We are committed to making participation in this project a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, gender identity and expression, level of experience, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Our standards

Examples of behavior that contribute to a positive environment include:

- Using welcoming and inclusive language
- Being respectful of differing viewpoints and experiences
- Accepting constructive criticism gracefully
- Focusing on what is best for the community

Unacceptable behavior includes harassment, discrimination, personal attacks, sexualized language or imagery, public or private intimidation, and publishing private information without permission.

## Enforcement

Report unacceptable behavior by opening a private report through the repository owner's GitHub profile or by contacting the maintainers through a GitHub issue marked as sensitive. Reports will be reviewed and handled fairly.

This code of conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
